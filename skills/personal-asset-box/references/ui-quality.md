# 素材盒界面质量

仅在新建或改动界面时阅读。

## 产品读法

先判断这是桌面素材工作台，而不是展示型网站。用户主要动作是连续导入、快速打标签、组合筛选和取出原图。视觉风格服务于缩略图识别与操作速度。

## 布局

- 顶部保留搜索和导入等全局动作。
- 左侧放全部、待整理和标签筛选。
- 中央用能看清内容的缩略图网格，选中态明显。
- 右侧编辑当前素材；没有选中时显示有用的空状态。
- 窄窗口可以折叠侧栏或把详情改为抽屉，但桌面主路径不能被藏进多层页面。

## 交互

- 导入入口同时支持文件选择和拖放，并显示支持格式。
- 点击标签即可选择；新标签输入提供已有标签补全。
- 多标签筛选明确采用“同时包含”，选中标签可一眼看见并单独移除。
- 保存、导入、恢复只在数据库事务完成后显示成功。
- 错误说明下一步，而不是只说“出错了”。
- 删除是唯一需要强确认的常规动作；备注、来源链接和标签都不设为必填。

## 视觉纪律

- 使用一套中性色和一个主强调色，确保文字、按钮、焦点环达到清晰对比。
- 卡片只承载一张素材及必要元信息，不添加虚构统计、无意义徽章或装饰文字。
- 圆角、阴影和边框使用一致规则；缩略图保持比例，不拉伸原图。
- 动效只用于状态变化和操作反馈，并尊重 `prefers-reduced-motion`。
- 每个可点击控件有可理解的文本或辅助名称；不要只靠 placeholder 充当表单标签。

## 状态完整性

至少设计空库、无筛选结果、导入中、保存中、成功和失败状态。数据仍在加载时不要短暂显示“0 张素材”造成误导。
