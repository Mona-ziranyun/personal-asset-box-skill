# 交付前验收清单

按本次改动范围执行相关项。任一核心项失败都不能声称完整交付。

## 核心行为

- [ ] 单张和多张 JPG、PNG、WebP 可以导入，其他格式有明确提示。
- [ ] 无标签导入后出现在待整理。
- [ ] 刷新和重新打开同一地址后，图片、标签、备注仍存在。
- [ ] 标签可添加、移除和复用，输入已有词时不会无意创建近义重复。
- [ ] 两个或更多标签筛选只返回同时包含全部选中标签的素材。
- [ ] 文件名、标签和备注搜索都能命中；无结果时状态清晰。
- [ ] 大图可查看，导出原图后文件可打开且格式不变。

## 数据安全

- [ ] 成功提示发生在写入完成之后；失败不会显示假成功。
- [ ] 完整备份包含图片字节及全部元数据。
- [ ] 备份可在独立空测试库恢复，恢复后原图和标签一致。
- [ ] 非法或不支持的备份不会写入半套数据。
- [ ] 删除前确认，删除只影响库内副本。

## 界面与质量

- [ ] 导入、搜索、待整理、筛选、详情和备份入口在首屏可发现。
- [ ] 键盘焦点可见，按钮和正文对比清楚。
- [ ] 缩略图不被拉伸，长文件名不会撑坏布局。
- [ ] 空库、无结果、加载、保存和错误状态都有对应反馈。
- [ ] `npm run build` 通过，浏览器控制台没有未处理错误。
